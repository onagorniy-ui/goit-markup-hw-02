# goit-markup-hw-02

Домашнє завдання №2 з курсу верстки HTML/CSS (GoIT).

## Опис
Стилізація сторінки WebStudio (CSS, шрифти, кольори, базовий скидання стилів):
- Підключення нормалізатора стилів `modern-normalize`
- Підключення Google Fonts (`Roboto`, `Raleway`)
- Оформлення тексту, кольорів фону та посилань згідно з макетом
